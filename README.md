# Damson Cloud Platform SDLC stuff

This repository contains all the stuff related to DCP's SDLC setup, including common components used during CI/CD on GitHub Actions, common setup pieces for devenv, etc.

## Contents

See each component's `README.md` file for more details.

* `./github/actions` - reusable GitHub Actions actions.
* `./devenvbase` - reusable base for devenv configurations.

## Contributing

Use `devenv` environment for building, testing, executing, running code. It ensures use of tools specific to this particular project.

### Start shell

To start devenv shell, use `devenv shell` command.
